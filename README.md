# ChatGPT-like AI Starter
Full-stack starter: React/Vite frontend + Express backend.

## Run
Terminal 1:
cd backend
npm install
npm run dev

Terminal 2:
cd frontend
npm install
npm run dev

Copy backend/.env.example to backend/.env and add your AI provider key.
Never put secret API keys in frontend code or GitHub.

The chat endpoint is ready as a provider adapter. Replace the demo section in backend/server.js with your chosen AI provider SDK/API.
